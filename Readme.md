## 📌 Overview

**AI Career Agent** is an end-to-end job application assistant that helps candidates create, optimize, and tailor ATS-friendly resumes while automatically discovering relevant opportunities.

Instead of simply generating resumes, the bot acts as your personal career assistant:

- Builds Harvard-style resumes from voice or text
- Parses existing resumes
- Analyzes GitHub, Behance, or portfolio projects
- Finds matching jobs
- Tailors resumes using the STARL framework
- Generates application cheat sheets
- Writes personalized cover letters
- Sends daily curated job alerts

> 💡 **One bot. One conversation. Everything needed to apply for jobs faster.**

---

## ✨ Key Features

- 🎙️ **AI Resume Generation** — Generate a complete Harvard-style resume from simple voice notes or text using `/generate`.
- 📄 **Resume Parsing** — Upload an existing PDF resume and instantly convert it into structured data.
- ✨ **STARL Resume Tailoring** — Rewrites achievements using the Situation, Task, Action, Result, Learning framework.
- 🧠 **Gap Interview Engine** — Identifies missing experiences and asks only the questions needed to maximize ATS scores.
- 🐙 **GitHub / Behance Analysis** — Automatically extracts your strongest projects and converts them into recruiter-ready bullet points.
- 🎯 **AI Job Matching** — Ranks scraped jobs based on your resume and predicts your best opportunities.
- 🔍 **Multi-Platform Job Search** — Search opportunities by role and location directly from Telegram.
- 📝 **Application Cheat Sheets** — Predicts difficult application questions and generates copy-paste answers.
- 💌 **Tailored Cover Letters** — Creates personalized cover letters for every application.
- 📊 **Harvard ATS PDF Engine** — Produces clean, recruiter-friendly PDFs.
- 🌅 **Daily Job Alerts** — Receive fresh AI-ranked opportunities every morning.
- ⚡ **Intelligent Resume Management** — Automatically keeps your master resume and portfolio synchronized.

## 🚀 Quick Start

1. Open the Telegram bot:
   **[@znode_resume_agent_bot](https://t.me/znode_resume_agent_bot)**

2. Type:

```
/start
```

3. Choose one of two onboarding methods:

- 📄 Upload an existing resume PDF
- 🎙️ Use `/generate` to build one from scratch

4. Link your:

- LinkedIn
- GitHub
- Behance
- Personal Portfolio

5. Start applying:

- `/scrape` to discover jobs
- `/tailor` to optimize for a specific role

---

## 🤖 Bot Commands

| Command | Action |
| :--- | :--- |
| `/start` | Start the AI Career Agent |
| `/generate` | Generate a complete Master Resume using voice or text |
| `/changeresume` | Upload a new PDF Master Resume |
| `/github` | Sync GitHub, Behance, or Portfolio projects |
| `/scrape` | Search and rank jobs by role & location |
| `/tailor` | Tailor your resume to a specific job description |
| `/stop` | Pause daily job notifications |
