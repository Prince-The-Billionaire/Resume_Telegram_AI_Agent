## 📌 Overview

**ATS Resume Bot** automatically tailors your resume for target positions, scores ATS compatibility, and generates recruiters-ready application materials directly within Telegram[cite: 2].

> 💡 **Why use it?** Stop applying with a static PDF. Get tailored bullet points, custom cover letters, and Harvard-formatted resumes tailored to every posting[cite: 2].

---

## ✨ Key Features

- 🔎 **Smart Job Scraping** — Aggregates large batches of real-time listings from LinkedIn, RemoteOK, Jobberman, and X (Twitter) via dynamic dorking.
- 🎯 **Gap Interview Engine** — Uncovers hidden achievements through quick follow-up prompts[cite: 2].
- 📄 **Harvard-Style PDF Engine** — Produces clean, ATS-optimized PDFs automatically[cite: 2].
- 📊 **ATS Scoring & Recruiter Feedback** — Get actionable insights before submitting[cite: 2].
- ⚡ **Auto-Fixes** — Apply high-impact ATS optimization in a single step[cite: 2].
- 🛠 **GitHub Profile Analysis** — Turns technical repositories into recruiter-ready project bullets[cite: 2].
- 📈 **Campaign Tracking** — Automatically tracks user acquisition sources via Telegram deep links for advertising analytics.
- 🔔 **Daily Alerts** — Tailored morning updates delivered right to Telegram[cite: 2].

## 🚀 Quick Start

1. Start a chat on Telegram: **[@znode_resume_agent_bot](https://t.me/znode_resume_agent_bot)**[cite: 2]
2. Send `/start` to view the comprehensive command menu.
3. Upload your master resume (`.pdf`)[cite: 2].
4. Link your LinkedIn and GitHub profiles[cite: 2].
5. Use `/scrape` or paste a target job description with `/tailor`[cite: 2].

---

## 🤖 Bot Commands

| Command | Action |
| :--- | :--- |
| `/start` | Restart the bot and view the instructional menu |
| `/scrape` | Search active job openings by role & location |
| `/tailor` | Instantly tailor resume to a pasted job description |
| `/fixissues` | Automatically apply recommendations to your last tailored draft |
| `/changeresume` | Replace your master resume base file |
